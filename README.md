# Data Career Analysis (Power BI)

A data exploration and visualization project using Power BI to analyze survey data about professionals working in data-related careers.

## Overview

Explored survey data to examine various aspects of working in the data industry, including compensation, work-life balance, demographics, geographic distribution, and perceived barriers to entering the field.

## Development Context

**Guided Learning Project**

Completed while following instructional material focused on data analysis and visualization using Power BI. The project provided hands-on experience exploring survey data, comparing responses, and presenting findings through interactive visualizations.

## Tools & Technologies

- Microsoft Power BI
- Data Analysis
- Data Visualization
- Exploratory Data Analysis

## Features

- Analysis of average salaries across data-related professions
- Exploration of work-life balance and job satisfaction
- Demographic analysis, including ethnicity and country of origin
- Examination of perceived barriers to entering the data industry
- Comparison of characteristics across data-related careers
- Power BI visualizations for exploring survey findings

## Learning Objectives

- Develop practical experience using Microsoft Power BI.
- Explore and analyze survey data.
- Compare responses across professional and demographic categories.
- Create visualizations to communicate survey findings.
- Practice interpreting and presenting data-driven insights.

## Analytical Considerations

The findings represent the survey respondents included in the dataset. They should not automatically be interpreted as representative of everyone working in data-related careers.
